Data Flow — Filter Change Lifecycle

1
User selects a filter value
One of 4 dropdowns in FilterBar.vue updates — e.g. Location → "Tokyo"
FilterBar.vuev-model="selectedLocation"
2
Singleton state updates
useFilters.js holds 4 reactive refs shared across all views. hasActiveFilters computed re-evaluates.
useFilters.jsselectedLocation.value = "Tokyo"
3
Component watcher fires
Each view watches getCurrentFilters(). Keys are mapped: selectedLocation → warehouse, selectedPeriod → month.
watch(getCurrentFilters, loadData)
4
HTTP request constructed in api.js
Only non-"all" values are appended to URLSearchParams, keeping the query string minimal.
axios.getGET /api/orders?warehouse=Tokyo
5
FastAPI filters in-memory
apply_filters() and filter_by_month() run list comprehensions against the loaded JSON. No DB query — pure Python.
apply_filters(orders, "Tokyo")filter_by_month(orders, None)
6
Pydantic validates the response
FastAPI serializes filtered results through response_model (e.g. List[Order]), enforcing schema before returning JSON.
response_model=List[Order]
7
Vue re-renders via computed
Raw data stored in refs (allOrders). Derived data lives in computed properties. Reactivity graph re-evaluates and the template updates automatically.
allOrders.value = response.datacomputed filteredItems
